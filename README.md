# BELEAF Render Service v2

แทนที่ตัวเดิมที่ `https://beleaf-render-service.onrender.com/render`
สัญญา API เหมือนเดิมทุกอย่าง — n8n Workflow 3 ไม่ต้องแก้ก็เรียกได้

- `POST /render` รับ JSON เดิม คืน `image/png`
- `Authorization: Bearer <token>` (ตั้งผ่าน env `RENDER_AUTH_TOKEN`)
- `GET /health` ไว้เช็กว่าเซิร์ฟเวอร์ตื่นอยู่

## สิ่งที่แก้เทียบกับตัวเดิม

| ปัญหาที่พบในภาพจริง | สาเหตุ | แก้ยังไง |
|---|---|---|
| กล่องข้อความบางอันมีพื้น บางอันเป็นตัวลอย | ตัวเดิมอ่านทั้ง `overlayText` (3) และ `panel.overlayText` (5) | ใช้ `overlayText` แหล่งเดียว ถ้าไม่มีค่อย fallback |
| พาดหัวเป็นแถบยาวเต็มขอบ เหลี่ยมคม | ตัวเดิมไม่อ่าน `renderDirectives.bannerMode` | อ่านแล้ว `tag` = ป้ายมุมมนเว้นขอบ 5.5% |
| ตัวหนังสือเล็ก | ไม่เคยมีค่าขนาดฟอนต์ใน payload เลย | คำนวณจาก `fontScale` เป็นสัดส่วนความสูงภาพ |
| มุมไม่มน ไม่มีเงา | ตัวเดิมไม่ใช้ `cornerRadius` / `shadow` | ใช้ค่าจากชีต 19/20 จริง |
| ตัวอักษรขาวบนส้ม อ่านยาก | ฝังสีขาวไว้ตายตัว | คำนวณความสว่างพื้น เลือกดำ/ขาวอัตโนมัติ |
| อีโมจิทับตัวหนังสือ | แทรกกลางประโยค | ดึงออกจากข้อความ วางเป็นสติกเกอร์มุมบนซ้าย |
| ลายน้ำ `1/1` | ตัวเดิมวาดเอง | ไม่มีแล้ว |
| ข้อความล้นออกนอกภาพ | ไม่มีตัวย่อ | ย่อขนาดอัตโนมัติจนพอดีกรอบ |

## ตัวเลขที่ใช้ (วัดจากโพสต์ Dr.PONG ที่แชร์สูง)

- พาดหัว = 7.6% ของความสูงภาพ (เดิมได้ราว 5%)
- ข้อความในกล่อง = 4.2% (เดิมราว 2.5%)
- ป้ายพาดหัวเว้นขอบซ้าย 5.5% มุมมนตามชีต (24px)
- กล่องข้อความวางสลับซ้าย-ขวา 3 แถว หลบกลางภาพไว้ให้สินค้า

ปรับได้ที่ค่าคงที่ `SCALE` และ `SLOTS` บนหัวไฟล์ `server.js`

## วิธีขึ้น Render.com

1. อัปโหลด 3 ไฟล์นี้เข้า repo (`server.js`, `package.json`, `Dockerfile`)
2. ที่ Render เลือก **Docker** เป็น environment (จำเป็น เพราะ Playwright ต้องมีเบราว์เซอร์ติดตั้ง)
3. ตั้ง env `RENDER_AUTH_TOKEN` = `79e1a54fbbda35b5b49b8904f5726bd0` (ค่าเดิมที่ n8n ใช้อยู่)
4. Deploy แล้วลอง `GET /health` ต้องได้ `{"ok":true}`

**อย่าเพิ่งลบตัวเดิม** — ถ้าอันใหม่ไม่ถูกใจ ให้ชี้ URL กลับไปที่ตัวเก่าได้ทันที
URL อยู่ในโหนด `Render Service Config` ของ Workflow 3

## ข้อจำกัดที่ต้องรู้

- ผมไม่เคยเห็นซอร์สโค้ดตัวเดิม เขียนขึ้นใหม่จาก payload จริงที่ดักจับได้ตอนรัน execution 351
  ถ้าตัวเดิมมีลูกเล่นอะไรที่ไม่ปรากฏใน payload อันใหม่จะไม่มี
- ฟอนต์ดึงจาก Google Fonts ตอนเรนเดอร์ ถ้าเซิร์ฟเวอร์ออกเน็ตไม่ได้จะกลายเป็นฟอนต์ระบบ
- ทดสอบบนเครื่องผมไม่ได้ (ติดตั้ง Playwright ไม่ได้) — ตรวจแค่ไวยากรณ์ JavaScript ผ่าน
